# Контекст

Категории, коллекции и товары имеют вложенные финские URL и должны разрешаться из контролируемых реестров. Отдельные динамические маршруты для каждого результата пересекались бы по владению путями и расходились бы при изменении структуры каталога.

# Решение

Все outcomes каталога — категория, коллекция и товар — принадлежат одному catch-all маршруту `tuotteet/[...segments]`. Он разрешает только опубликованные controlled paths; карточки и хлебные крошки получают ссылки из тех же реестров.

# Почему

Это решение фиксирует D01. Отклонён вариант с независимыми деревьями маршрутов для категорий, коллекций и товаров: он создаёт конкурирующих владельцев одинаковых URL и делает эволюцию slug-ов рискованной.

# Последствия

Новый тип outcome добавляется в реестр и его resolver, а не новым маршрутом. Рендеринг вложенных outcomes должен оставаться согласованным с resolver-ом; неизвестный или устаревший путь не может становиться товаром по предположению.
