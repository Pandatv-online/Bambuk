# Контекст

Фильтрация по категориям, коллекциям и наблюдаемым атрибутам должна быть ссылочной, возвращаемой при навигации и одинаковой на desktop и mobile. Некорректные значения параметров не должны создавать бесконечные или индексируемые варианты страницы.

# Решение

Состояние фильтра, сортировки и страницы принадлежит URL query. Facet values разбираются только по контролируемому каталогу; неизвестные значения игнорируются и канонизируются. Результат и пагинация рендерятся на сервере, а до финальной SEO-политики страницы с фильтрами остаются noindex.

# Почему

Отклонён вариант хранения фильтра только в клиентском состоянии: он ломает ссылку, возврат браузера, повторяемость результата и усложняет безопасное SEO-поведение.

# Последствия

Sidebar и мобильная фильтр-панель являются двумя доступными представлениями одного query contract. Изменение набора facets потребует миграции parser-а и тестов canonicalization, а не согласования независимых UI-состояний.
