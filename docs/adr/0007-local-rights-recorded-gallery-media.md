# Контекст

Галерея и товарные страницы должны показывать изображения без внешних visitor-запросов, но доступные reference assets не доказывают связь с конкретным товаром, проектом или заказчиком. Полная замена медиасистемы после публикации привела бы к большому числу битых ссылок и неясным правам.

# Решение

Посетителю выдаются только локальные зарегистрированные файлы с `rightsId`, source metadata, alt и fallback. Галерея фильтрует лишь наблюдаемый тип сцены, а не предполагаемую товарную или клиентскую связь; lightbox реализует клавиатурное управление, возврат фокуса, Escape, scroll lock и reduced motion.

# Почему

Отклонены hotlink на исходный сайт и подписи, выводящие конкретный товар или проект из изображения: первый создаёт зависимость от чужого хоста, второй публикует неподтверждённое утверждение.

# Последствия

Каждый новый файл требует записи о происхождении и правах до регистрации. Переиспользование изображения на product page возможно только при явной применимости; UI не должен компенсировать её отсутствия маркетинговой подписью.
